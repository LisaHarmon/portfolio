# Installation Guide

Purpose of this Guide


Overview

This guide provides instructions for using the [Product] Installer to perform system installations, upgrades, and uninstallations. System administrators use the Installer to download and execute the program files needed to run [Product] applications.

> If you have questions or concerns regarding any aspect of the PRODUCT NAME system, please don’t hesitate to contact us.
Appendices have also been included to provide some foundational information that is not required for the installation but may be of interest to technical staff.

The Installer was created to consolidate and simplify the steps required to perform installations, uninstallations, and upgrades of multiple Components on client systems. 
This is achieved by allowing you to select targeted Cores and/or Components from a checklist, then input data for each category of selected Components that is then propagated across multiple corresponding MSI files – thus accelerating setup and deployment..

The basics of this tool are that it:

* is a centralized installer
* is designed in Wizard-style format
* provides roadmap-like status on the left side of the screen (non-navigational)
* automatically uninstalls any previous version (i.e., 5.1 or later) of the MSI files before it installs any newer version. 

Before You Begin

Before using the Installer to install, upgrade, or uninstall [Product] program files:

* Confirm you have system administrator priviledges in the [Name] application.

    > System administrator permissions are set in the [name] application. 

* Ensure your system meets the [system requirements].
* If applicable, determine the current [Product] version installed on the machine where you want to install, upgrade, or uninstall [Product] program files.
* Copy any custom configuration files.

    > Custom configuration files are located in [folder path]

* Back up the [Product] database.
